# Sample artifact: Expanded Event Input System Plus

A WordPress plugin (custom Event post type, meta boxes, admin columns, an
`[eeis_upcoming_events]` shortcode, and a WooCommerce booking REST endpoint),
ingested from the uploaded `So_cooking_.pdf`.

It is **sample content**, not part of the SNI toolchain — it represents the kind
of skill/content artifact an SNI-managed workspace would track. It is kept here
so nothing from the ingest is lost. The authoritative source is the original
PDF; this directory is a provenance note rather than a runnable plugin checkout.
